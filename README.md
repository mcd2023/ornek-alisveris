# Köyüm Mandıra — GitHub Pages

Bu proje tamamen statik HTML/CSS/JS yapısındadır ve GitHub Pages üzerinde çalışır.

## Yayına alma
1. Bu klasörü GitHub'da yeni bir repository'ye yükleyin.
2. `Settings > Pages` bölümüne girin.
3. `Build and deployment` altında `Deploy from a branch` seçin.
4. Branch olarak `main`, klasör olarak `/ (root)` seçin.
5. Kaydedin.

## Özelleştirme
- `images/hero.jpg` dosyasını kendi kapak görselinizle değiştirin.
- `index.html` ve `iletisim.html` içindeki WhatsApp bağlantısını gerçek numarayla değiştirin.
- İletişim sayfasındaki harita alanına Google Maps iframe ekleyin.
- Ürün görsellerini `images/` klasörüne koyup ürün kartlarını güncelleyin.

Not: Bu çalışma mevcut sitenin kaynak kodunun kopyası değildir; GitHub Pages'e uygun, özgün bir yeniden tasarım iskeletidir.
